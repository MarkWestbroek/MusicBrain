An 8-voice analog audio patch matrix: 8 input buses by 16 output buses, each bus eight voices wide. Patches are stored and recalled in software — press a button and the whole analog routing snaps into place, per voice if you want it (split 8 voices into 2x4 with independent routing). Built around eight MT8816 crosspoint chips, one per voice, socketed. Output bus 16 is reserved as a measurement bus into the ADC so the brain can calibrate levels automatically. Two placement variants exist: v0.2 (edge) and v0.3c (center, 34% shorter audio traces).
