# RP2040 (Raspberry Pi Pico)

## What it is
Microcontroller chip designed by Raspberry Pi: **dual‑core Cortex‑M0+ @ 133 MHz, 264 KB SRAM, no internal flash** (external QSPI flash on the module, typically 2 MB on a Pico). Sells for around €1 in bulk; the Pico board for ~€5.

Notable peripheral: **PIO** ("Programmable I/O"), 8 tiny state machines that can implement custom serial protocols in hardware — SPI slave, WS2812, quadrature decoder, custom bus timing — without burning CPU cycles.

A successor, **RP2350**, adds a second core variant (Cortex‑M33), more RAM, security peripherals, and optional hardware floating‑point. We treat it as a drop‑in faster RP2040 for our purposes.

## Why we use it (ADR 0001)
- Cheap, widely available, dual core (one core can run the realtime loop, the other handles communication).
- PIO is the right tool for the **SPI‑slave + S&H + CD4051 mux** timing on breakout boards (see [dac-sh-mux.md](dac-sh-mux.md)).
- C/C++ SDK (pico‑sdk) and **Arduino‑Pico** core both supported by PlatformIO.
- Pin‑compatible boards from many vendors → less lock‑in.

## What matters for MusicBrain
- **Breakouts**: default MCU. One core handles SPI/CAN frames; the other runs the 20–50 kHz interpolator and writes the DAC.
- **Project 1 / 2 brain alternative**: fine for small switchers when no Teensy is at hand.
- **No CAN‑FD hardware**: bridge nodes (ADR 0006) use STM32G4 or Teensy + transceiver instead.
- **USB**: full USB 1.1 device, supports CDC + MIDI classes; no USB host (Pico W variant adds WiFi/BT via CYW43 chip but still no USB host).

## Gotchas
- **No on‑chip flash**: code runs XIP (eXecute‑In‑Place) from external QSPI flash, which is slower than internal flash. Cache is small; hot ISRs should be marked `__not_in_flash_func` or copied to RAM.
- **No FPU on the M0+** (Pico/RP2040): floating point is software‑emulated and slow. Use fixed‑point in DSP code. RP2350's M33 cores can have hardware FP.
- **PIO is powerful but a separate skill**: assembly‑like, 32‑instruction programs. Worth the learning investment for the breakout SPI slave; not needed elsewhere.
- 3.3 V I/O, not 5 V tolerant.
- Two SDKs exist (pico‑sdk and Arduino‑Pico). Pick one per board and stick with it.
